# OneKey

OneKey is a Hyperliquid ecosystem app. Category: wallet.

## What it is

OneKey makes open-source hardware wallets (OneKey Pro 2, Classic 1S) and a self-custodial software wallet available as an app, browser extension and web app. Its app lets users trade crypto, stocks and other assets from the wallet. OneKey Perps, a built-in perpetual futures feature, supports crypto, equity, commodity and other markets with TP/SL, TWAP orders and funding history.

## How it relates to Hyperliquid

OneKey Perps executes trades on Hyperliquid's order book, including HIP-3 markets, with orders signed by the user's own OneKey keys.

## Hyperliquid data an app like this needs

- order book stream
- positions and liquidation prices per user wallet
- funding rate history
- HIP-3 market metadata
- TWAP order status
- candles
