# Unit

Unit is a Hyperliquid ecosystem app. Category: aggregator/bridge.

## What it is

Unit is an asset tokenization and bridging layer that lets users deposit and withdraw native assets such as BTC, ETH, SOL and AVAX to and from Hyperliquid. Deposits and withdrawals are verified by a Guardian network, and a public explorer shows each operation. Users trade the resulting assets on Hyperliquid spot markets and use them as collateral.

## How it relates to Hyperliquid

Unit supplies the native spot assets traded on Hyperliquid, with an initial Guardian set led by Unit, Hyperliquid Labs and Infinite Field, and one-click deposits on the Hyperliquid interface.

## Hyperliquid data an app like this needs

- spot balances per wallet
- deposit and withdrawal transfer events
- spot market metadata
- spot order book stream
- portfolio margin collateral state
