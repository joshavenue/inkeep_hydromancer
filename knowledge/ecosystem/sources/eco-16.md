# Dreamcash

Dreamcash is a Hyperliquid ecosystem app. Category: trading app/frontend.

## What it is

Dreamcash is a self-custodial trading app for iOS, Android, web, and macOS that combines perpetuals, spot, real-world asset markets, and prediction markets in one portfolio. It offers up to 40x leverage and an XP rewards system tied to weekly distributions. Users can create a new account or import an existing Hyperliquid wallet.

## How it relates to Hyperliquid

Dreamcash is built on Hyperliquid and lets users trade Hyperliquid spot, perpetuals, and HIP-3 markets through its own interface.

## Hyperliquid data an app like this needs

- order book stream
- candles
- HIP-3 market metadata (stocks, commodities, forex)
- user positions, orders, and fills
- funding rates
- trading volume per user for rewards tracking
