# fomo

fomo is a Hyperliquid ecosystem app. Category: copy/social trading.

## What it is

fomo is a social-first crypto trading app for mobile and web with a live trade feed, trader leaderboards, alerts on what top traders buy, and copy trading. It supports multichain, gasless memecoin and token trading with Apple Pay funding, and has added perpetuals on crypto, equities, indices, and commodities. Its website says 2,500,000 traders use it, mostly retail users.

## How it relates to Hyperliquid

fomo's official perps launch post says its in-app perpetuals are powered by Hyperliquid (alongside trade.xyz markets), so users trade Hyperliquid perps without bridging or using Hyperliquid's own interface.

## Hyperliquid data an app like this needs

- live positions and PnL for many wallets (leaderboards, feed)
- fills history per wallet for copy trading
- order book and trade streams
- HIP-3 market metadata for equity and commodity perps
- candles
- real-time user order and position updates
