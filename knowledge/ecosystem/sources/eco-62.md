# tread.fi

tread.fi is a Hyperliquid ecosystem app. Category: trading terminal.

## What it is

tread.fi is an algorithmic trading terminal and order execution management system that lets traders run execution algorithms, bots, and AI trading agents on their own CEX and DEX accounts from one interface. It offers a REST API with self-deployment options and an agent marketplace tied to its TREAD token. It describes its users as both retail traders and institutional trading firms.

## How it relates to Hyperliquid

tread.fi routes orders, bots, and agents to Hyperliquid perps, including HIP-3 pairs, and its TREAD staking for agent sponsor slots runs on HyperEVM.

## Hyperliquid data an app like this needs

- order book stream for execution algorithms
- fills history per wallet
- live positions and margin per connected account
- HIP-3 market metadata
- candles
- funding rates
