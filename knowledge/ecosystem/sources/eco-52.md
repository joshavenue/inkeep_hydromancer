# Quote

Quote is a Hyperliquid ecosystem app. Category: trading terminal.

## What it is

Quote is a trading terminal that splits algo orders (TWAP, VWAP, POV, Iceberg, Chase) into child orders so the full size never reaches the order book. It covers perps, spot, and prediction markets for crypto, equities, indices, commodities, and pre-IPO companies, and includes an AI assistant, news trading, and an enterprise REST API with a read-only MCP server. It is in private alpha.

## How it relates to Hyperliquid

The website does not name Hyperliquid directly, but its market list uses HIP-3 style tickers such as xyz:NVDA and xyz:SP500.

## Hyperliquid data an app like this needs

- order book stream
- trades stream
- fills history per wallet
- HIP-3 market metadata
- candles
- funding rates
