# HyperLink

HyperLink is a Hyperliquid ecosystem app. Category: market maker/infra.

## What it is

HyperLink is a prime brokerage layer for Hyperliquid aimed at power users, market makers, prop desks, algo traders, and AI agents. It offers lower trading fees, private order flow, and a web and mobile trading app. Its API mirrors the Hyperliquid API so existing strategies can switch by changing the base URL.

## How it relates to Hyperliquid

HyperLink routes client orders onto Hyperliquid's order book while keeping positions and orders private before settlement.

## Hyperliquid data an app like this needs

- order book stream
- fills history per wallet
- trading volume and fee tier per wallet
- live positions and margin for many wallets
- asset metadata and indexes, including spot markets
