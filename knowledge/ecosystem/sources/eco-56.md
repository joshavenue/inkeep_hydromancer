# Silhouette Exchange

Silhouette Exchange is a Hyperliquid ecosystem app. Category: market maker/infra.

## What it is

Silhouette is a block trading layer that uses request-for-quote (RFQ) so traders can get competing quotes from market makers for large orders without posting them to the public order book. It covers Hyperliquid perps and ecosystem assets such as tokenized equities. It is used by large traders and the market makers that answer quotes.

## How it relates to Hyperliquid

Trades settle on Hyperliquid across HyperCore and HyperEVM, and it describes itself as the universal block trading layer on Hyperliquid.

## Hyperliquid data an app like this needs

- order book stream
- mark and oracle prices
- fills history per wallet
- live positions for many wallets
- HIP-3 market metadata
