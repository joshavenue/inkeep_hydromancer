# Stingray

Stingray is a Hyperliquid ecosystem app. Category: telegram/trading bot.

## What it is

Stingray is an AI trading assistant that users message over iMessage or Telegram. A user shares a trade idea, Stingray turns it into a rule, shows how often the setup happened before, and sends a text alert if it happens again. The user decides whether to trade.

## How it relates to Hyperliquid

Not stated on its website; X users describe using its signals to trade Hyperliquid markets.

## Hyperliquid data an app like this needs

- historical candles for backtesting setups
- live prices for alert triggers
- funding rates and open interest
- liquidation feed
- market metadata for supported assets
