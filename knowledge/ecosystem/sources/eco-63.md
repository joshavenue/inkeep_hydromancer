# TrueNorth

TrueNorth is a Hyperliquid ecosystem app. Category: trading terminal.

## What it is

TrueNorth describes itself as an agentic brokerage where users deploy AI agents that scan markets, propose trades, and monitor positions, with alerts delivered to apps such as Telegram. Features include a funding rate arbitrage scanner across perp venues, an options flow desk, and a position watcher. It is non-custodial and connects to venues including Hyperliquid, Lighter, Binance, Bybit, and Bitget.

## How it relates to Hyperliquid

It started as a layer built on Hyperliquid and trades there through an agent wallet that can place trades but cannot withdraw funds.

## Hyperliquid data an app like this needs

- funding rates across markets
- order book stream
- live positions per user wallet
- fills history per wallet
- candles
- HIP-3 market metadata
