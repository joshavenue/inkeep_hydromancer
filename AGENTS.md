# Project agent instructions

## TypeSafe

Load and use the `typesafe-ai` skill when working on this Hydromancer/Inkeep project. If unavailable, read https://raw.githubusercontent.com/typesafe-ai/skills/main/skills/typesafe-ai/SKILL.md or install it using `npx skills add typesafe-ai/skills --skill typesafe-ai` and select your agent. Read the relevant live TypeSafe documentation before designing or implementing an integration. Follow its guidance on typed semantic judgments, evidence, uncertainty, and verification; keep exact rules, calculations, access controls, and execution in ordinary code.

Preserve the existing Inkeep architecture and the user's requested scope. Installing the skill alone does not authorize paid-service signup, sending private research or credentials to TypeSafe, replacing the chat model, or restarting the expired preview.

For the existing assistant's product-fit rules and deployment safeguards, also consult `website-ai-assistant` and this project's `README.md`.
